# TTS 読み正規化（英語・アルファベット）

VOICEVOX は日本語向けエンジンである。英字のまま渡すと、製品名や略語が破綻した読みになる（例: Gigatoken → 「ギガトケン」）。

## 原則

1. **画面テキストは英語のままでよい**（製品名・API名・コード）
2. **`cues.yaml` の `narration` は人間可読な SoT**（英字製品名を残してよい）
3. **TTS に渡す直前だけ**、辞書でカタカナ等へ正規化した `tts_text` を使う
4. **未知の英字語を自動ローマ字推測しない**（「もっともらしい誤読」を防ぐ）

```text
slides/*.md                 画面表示（英語可）
script/cues.yaml            narration = 意味上の SoT
script/pronunciation.yml    プロジェクト読み辞書
（任意）共通辞書            API / CPU など安定略語
        ↓ TTS 直前
audio/tts-input ログ        変換後・適用ルール・未解決語
        ↓
VOICEVOX audio_query / synthesis
```

## 辞書の階層

優先順位（高い順）:

1. スライド単位の明示 override（必要なときだけ）
2. プロジェクト辞書 `script/pronunciation.yml`
3. スキル／テンプレの共通辞書（任意・安定略語のみ）
4. 限定ヒューリスティック（例: 既知の全大文字略語を一字ずつ）
5. **未解決として報告**（黙って通さない）

プロジェクト固有語（Gigatoken、Anima、作品名）を共通辞書へ安易に入れない。同じ綴りでも案件で読みが違うことがある。

### プロジェクト辞書の例

```yaml
# script/pronunciation.yml
terms:
  Gigatoken: ギガトークン
  HuggingFace: ハギングフェイス
  tiktoken: ティクトークン
  Anima: アニマ
  ComfyUI: コンフィユーアイ
  SIMD: シムド
  API: エーピーアイ
  CPU: シーピーユー
  GPU: ジーピーユー
  WSL: ダブリューエスエル
  README: リードミー
```

マッチは最長一致・単語境界・大小文字ルールを決め、非再帰・冪等にする。

## 手書きと自動の境界

| 自動でよい | 手書き（辞書登録） |
|------------|-------------------|
| 辞書との完全一致置換 | 製品名・固有名詞の公式読み |
| 英字列の抽出・未登録警告 | 文脈で読みが変わる略語 |
| 変換レポート出力 | 一度きりの文脈依存（slide override） |

自動推測しない: 未登録 CamelCase、一般英単語の日本語読み、URL／識別子／コード断片。

エージェントは `narration` 本文を場当たり的にカタカナだらけに書き換えない。読みは辞書エントリとして残す。

## TTS アダプタへの組み込み

`generate-tts`（または同等）は次の順とする。

1. `narration` を読む
2. 辞書を適用して `tts_text` を得る
3. 未解決の英字語があれば WARNING／ERROR（製品名らしき語は ERROR 推奨）
4. `tts_text` で VOICEVOX を呼ぶ
5. 変換ログを `audio/` に残す（適用語・未解決）
6. 固有語・略語の初出を最低一度スポット試聴する

`narration` と意味内容は一致させる。読み変換は決定的に導出する派生物であり、SoT にしない。

## 採らない／後回し

| 手段 | MVP | 理由 |
|------|-----|------|
| 外部英語 G2P（eng_to_ipa 等） | 不採用 | 英語音素 ≠ 日本語慣用カナ。固有名詞で誤読しやすい |
| VOICEVOX `/user_dict_word` のみ依存 | 後回し | エンジン状態が SoT 化し、環境間で再現しにくい |
| `audio_query` アクセント句の常時編集 | 後回し | 語の読み正規化の主経路にしない |
| `narration` の直接カタカナ化 | 不採用 | 原稿の可読性・検索・字幕・`aligns_with` が壊れる |

ユーザー辞書 API を使う場合は、プロジェクト辞書から都度投入し、共有エンジンへ永続依存しない。

## 検証チェック

- [ ] `pronunciation.yml`（または同等）があり、動画内の主要固有語が載っている
- [ ] TTS 入力は辞書適用後である
- [ ] 未解決英字語がゼロ、または理由付き許可である
- [ ] 変換ログが残っている
- [ ] 固有語・略語の初出音声を確認した
