# 対話形式の原稿規範（解説役＋聞き手）

Updated: 2026/08/22 14:02

一方的な講義だと、視聴者の理解が止まった時点で以降が崩れる。
対話形式は話者を増やすためではなく、**キャラクター同士の会話劇として、つまずき・早合点・訂正を画面内に置く**ために使う。

VOICEVOX／ボイロ劇場の会話劇を優先する。説明資料の読み上げを二人に分けたものではない。

口調・会話劇の書き方は本ファイルを正とする。密度・前提・メタ分離は、呼び出し元の `dialogue` プロファイルが定める。本ファイルから劇場専用プロファイルを参照しない。

## いつ使うか

使う（`narration_mode: dialogue`）:

- 概念の理解確認、誤解の訂正、つまずきの先回りが中心の解説
- 手順の「なぜ」を追いつつ進める talk-through
- 劇場寄り（立ち絵・口パク・台詞字幕）で見せたい案件

使わない（`monologue` を維持）:

- 短い告知・チェックリスト・単独語りの手順読み上げ
- 会話劇そのものが目的でない、尺を増やしたくない案件

切替はキューの `meta.narration_mode` で明示する。未指定は `monologue`（現行互換）。

## 役割

| 役割 ID | 仕事 | やってはいけないこと |
|---------|------|----------------------|
| `teacher` | 境界・因果を示し、相手の反応に応じて訂正・補足する | 独白のまま聞き手を相づち係にする |
| `listener` | 固有の反応理由（早合点・勘違い・観察・反論）で返す | 「自信ない」と宣言する／すぐ完璧要約する／分かっていないフリで分かった喋りをする |

実話者名（VOICEVOX キャラ等）は役割 ID に書かず、`meta.speakers` で解決する。

## 会話劇としての書き方（主規範）

dialogue の各発話は、**キャラが今その場で反応している口調**で書く。

良い:

- 具体的な読み違い・早合点・言いかけ・観察・短い反論
- 相手の直前の発話への応答になっていること
- 短い台詞を切ってテンポを作ること（1 発話を説明文で埋めない）
- キャラの一人称・呼称・癖を案件プロフィールに合わせること（一人称は主語・目的語。文頭の飾りにしない）

悪い:

- 「ちょっと自信ない」「まだ分からない」など、不安をメタ宣言するだけ
- 分からないと言いながら、実際は整理済みの解説口調で喋る
- 講義原稿を二人で交互に音読するだけ
- 綺麗な説明文の拍（認知リズム）を各台詞に機械適用する
- 制作意図や要約を台詞として喋らせる／字幕に出す
- 一人称を文頭に置いて相槌・フィラー・呼び掛けにする（「私、そっちにするの？」）

参考にする空気感（案件外の一般論）:

- ボイロ劇場の台本は、印象的な反応と導入→展開→回収の会話で進む
- 説明の正しさより、**今の発話が次の返答を必要にするか**を優先する

## 発話可能性と意味の明確さ

自然さは、個別の禁止語を増やすことではなく、人物がその場で口にする文として意味を復元できるかで判定する。

- 原資料や会話上の必要性から求められていない新奇な比喩、擬人化、広告コピー調、詩的な名詞断片を、説明を補うために発明しない。
- 日常語として定着した慣用表現や、直前発話への短い反応は、指示対象が明らかで一度で意味を取れるなら禁止しない。
- 各台詞から「何が、何に、どうなったか」または「何を尋ねているか」を一文で復元できるようにする。
- 主体・対象・動作・結果の関係が曖昧なときは、比喩を足さず、普通の動詞・具体例・対比・言い換えで直す。
- 自然さはフィラーや崩しすぎた語尾ではなく、普通の語順と直前発話への応答で作る。

## 1 枚あたりの流れ（柔軟）

```text
解説役が事実／境界を出す
  → 聞き手が具体的に噛みつく／早合点する
  → 解説役が差分だけ直す
  →（必要なら）短い確かめ合い
```

内容が厚いスライドでは、理解確認を省略しない:

```text
質問 → 回答 → 相槌または訂正 → 軽い確認質問 →（必要なら）再解説
```

- 毎スライドで全フェーズを機械的に踏まないが、**密度 `high` では往復と確認を削らない**
- 「ここまで大丈夫？」の実況確認より、相手の言い直しや選択で確かめる
- 誤解は即座に全面否定しない。どこまで近いかを salvage してから差分を出す
- スライドごとに、呼び出し元の `dialogue` プロファイルが定める発話数・話者交替の下限を点検する

## 前提説明（技術 dialogue）

専門語を知っている前提で始めない。

- ユーザーが「これが分からない」と指定した語を優先し、AI が対象内容から不足分を補う
- 早い枚で「この動画での意味」を短く置く。カタカナ読みを字幕に出して説明したつもりにしない
- 後半で突然出る語がないか、生成後に用語スキャンする

## メタ指示と動画本文の分離

依頼文の reasoning effort・校正指示・内部作業指示・参照タスク ID などは **制作条件**であり題材ではない。
それらをスライド・台詞・読み辞書へ入れない（例: `extrahigh` を製品用語として訂正説明する失敗）。

## 字幕・画面表示

- 字幕は**現在発話中の台詞だけ**を出す（話者名タグは可）
- 「ひまり（解説）：〜が目的ではない」のような制作メモ／要約カードは出さない
- 説明すべき概念はスライド本文・図・ハイライトで担保し、字幕で補講しない
- 長い台詞は発話を分割し、字幕はおおむね 1〜2 行に収める

## 立ち絵・口パク（任意プロファイル）

劇場レイアウトを使う案件の目安（グローバル必須ではない）:

| 要素 | 目安 |
|------|------|
| 解説役立ち絵 | 左下 |
| 聞き手立ち絵 | 右下 |
| スライド本文 | 上部〜中央（立ち絵・字幕と安全域を分離） |
| 台詞字幕 | 中央下（立ち絵と被らない） |

口パクは開閉 2 枚の切替で足りる。発話中のみ開閉し、相手の発話中・間は閉じる。
表情は発話ごとまたは意味の転換点だけで変える。

レンダはページ単位（または動きの切れ目単位）のクリップを書き出し、最後に結合すると差し替えしやすい。

## cognitive-rhythm / JT writing との関係

| 対象 | 主規範 |
|------|--------|
| 枚の論理順・用語導入・画面の情報提示 | `japanese-technical-writing`（台詞の表面文体・常体指定は直接適用しない） |
| **dialogue の各台詞** | **本ファイル（会話劇）** |
| monologue の原稿の拍・緊張 | `cognitive-rhythm-writing` |
| dialogue での cognitive-rhythm | **場面接続・話題転換の回収のみ**（各台詞へ機械適用しない） |
| 尺・同期・TTS・立ち絵状態 | `timeline-and-sync.md` / `tts-and-stack.md` |

## キャラクター呼称・一人称

キャラクター音声を使う案件でのみ、公式またはユーザー指定のプロフィールを適用する。

- **VOICEVOX 劇場プロファイル**: 口調・一人称・相手の呼び方の SoT は [ボイボ寮](https://voicevox.hiroshiba.jp/dormitory/)（[呼称表](https://voicevox.hiroshiba.jp/dormitory/call_names/)）。既定ペア（冥鳴ひまり＋春日部つむぎ）では `voicevox-theater-video` の `call_names` 既定をそのまま使ってよく、制作のたびに寮を開き直さなくてよい
- 親 skill（monologue／通常 dialogue）の共通既定に特定キャラ・呼称・立ち絵配布元を固定しない
- **劇場プロファイル**（`voicevox-theater-video`）は、明示上書きが無いときの話者／素材／呼称の**プロファイル既定**を持ってよい（役割 ID はキューに残し、話者名は `meta.speakers` またはプロファイル既定で解決）
- 別キャラ／別ペア、またはユーザーが寮と異なる呼称を指定したときだけ寮を確認して上書きする。未確認の推測で呼称を補完しない
- 素材の利用条件・クレジットは案件ごとに確認する

### 一人称の使い方

`call_names` の一人称は、話者自身が主語または目的語になるときに使う値である。毎発話へ挿入して「一致」を作るものではない。

- 使う: 自分が主語・目的語のとき（「私は〜と思う」「あーしはこっちの方がしっくりくる」）
- 使わない: 相手の行為を問う／観察する文。呼び掛けは二人称側の呼称（`teacher_to_listener` / `listener_to_teacher`）か、呼称なし
- 禁止: 文頭の「一人称、」を相槌・フィラー・呼び掛けにする。読点の直後が相手の行為だと、一人称が相槌に聞こえる
- 不要なら出さない。一人称を使わない台詞の方が自然なら、それが正

## 自己点検（原稿）

- [ ] 各台詞が会話劇として自然で、説明文の読み分けになっていない
- [ ] 未依頼の新奇な比喩・擬人化・広告コピー調の表現を説明補完のために追加していない
- [ ] 各台詞の主体・対象・動作・結果、または質問内容を一度で復元できる
- [ ] 述語と対象の組み合わせが自然で、意味不明な名詞断片や動作表現が残っていない
- [ ] 聞き手がメタな不安宣言や優等生要約をしていない
- [ ] 「分からない」態度と、実際の情報量・整理度が矛盾していない
- [ ] 字幕が制作メモ／要約カードになっていない
- [ ] 役割 ID と `meta.speakers` が対応している
- [ ] 呼称・素材クレジットを使うなら案件内の出典がある
- [ ] 一人称を使う発話では話者が主語または目的語になっている。文頭の「一人称、」が相槌・呼び掛けになっていない
- [ ] 密度に応じた発話数・話者交替・理解確認がある
- [ ] 前提語が未説明のまま多用されていない
- [ ] メタ指示語が本文／読み辞書に混入していない
