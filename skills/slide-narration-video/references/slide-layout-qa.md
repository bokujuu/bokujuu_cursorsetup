# スライド配置 QA（文字はみ出し・画像アスペクト）

最終成果物は Marp 書き出し PNG である。Markdown 上の行数や「収まったつもり」では合否を決めない。

## 失敗の定義

次は失敗である。

1. **文字はみ出し** — 本文・表・コード・補足の文字がスライド端で水平に切れる、または安全帯を越えて端に接触する
2. **画像アスペクト歪み** — 埋め込み画像が自然比と異なる比率で表示され、押しつぶされて見える
3. **見えないクリップ** — `overflow: hidden` や過度な縮小で欠落が観測不能になっている

悪いのは「情報が厚い」ことではない。厚い箇条・具体例は維持したまま、収まらないときは配置と枚分割で直す。

## 安全域（目安）

- 上下左右に十分な `padding` を確保する（テーマ依存。uncover なら余白を削らない）
- **下端を補足 `.note` の常設領域にしない**。喋り専用・脚注は `cues.yaml` 側へ退避する
- ページ番号・テーマ装飾と本文が重ならないよう、下端に「本文を置かない帯」を意識する

厳密な px 閾値は実装 PR で固定する。規範上の合否は「PNG で文字が欠けていない」「画像が歪んでいない」である。

## CSS・Markdown の禁止／推奨

### 文字・レイアウト

| 禁止 | 推奨 |
|------|------|
| はみ出し対策としての `overflow: hidden` | 枚分割・退避・階層整理 |
| 内容量に応じた無制限の自動フォント縮小 | 明示 `compact-*` クラス＋最小サイズ下限 |
| スライド全体の `transform: scale(...)` | 局所調整のみ |

### 画像

| 禁止 | 推奨 |
|------|------|
| `width` と `height` の独立固定で押しつぶす | 片方だけ指定、もう片方は `auto` |
| 非等方の `scaleX` / `scaleY` | `max-width: 100%; height: auto;` |
| 情報図の既定 `object-fit: cover` | 固定枠が必要なら `object-fit: contain` |

推奨 CSS（テーマ style に含めてよい）:

```css
img {
  max-width: 100%;
  height: auto;
}
```

## レンダ前 lint（警告のみ）

必須ゲートにしない。高リスクの早期警告に使う。

- 長いコードフェンス・長い単一行（URL・CLI）
- 列数の多い表・長いセル
- 見出し＋表＋コード＋補足の縦積み
- 下部固定の `.note` / 脚注
- 画像への両軸固定サイズ指定

## レンダ後ゲート（必須）

工程 2.5 で行う。

1. Marp → PNG（`--allow-local-files`）
2. **各 PNG を画像として目視する**（必須。エージェントに画像読取手段があればそれを使う）
3. 下端・左右端で文字が欠けていないか確認する
4. 埋め込み図が押しつぶされていないか確認する（円が楕円、正方形が長方形など）
5. NG なら下記の修正順で直し、再レンダする。合格するまで工程 3 に進まない

機械検査スクリプト（PNG 画素／DOM 矩形）は後続実装とする。未実装でも、エージェントの PNG 目視ゲートは省略しない。

### ERROR / WARNING（将来の機械検査用）

| 級 | 意味 | 扱い |
|----|------|------|
| ERROR | 前景が端に接触／文字欠け／明らかな歪み | 再レンダ必須 |
| WARNING | 安全帯侵入・余白逼迫 | 該当枚を重点目視 |

ページ番号・uncover 装飾は除外対象。除外を全体設定へ安易に昇格させない。

## はみ出し・収まらないときの修正順

「要約しすぎない」を壊さないための順序。**最初に具体例・因果・条件を削らない。**

1. 喋り専用 note／脚注を `cues.yaml` に退避する
2. 重複表現・進行実況だけを除く
3. 表の比較軸・コードの注目範囲を絞る（意味単位で改行）
4. **意味の切れ目で枚分割する**（自動分割しない。主張とナレーション接続を維持）
5. 図と箇条の配置を組み替える
6. 明示 compact クラスで局所フォント調整（下限を下回らない）
7. 情報削除は最後の手段

`overflow: hidden` で隠すのは修正ではない。

## 画像が収まらないとき

1. 比率を保ったまま `max-width` で縮小する
2. 余白・箇条との配置を組み替える
3. 図専用枚へ分割する（キャプション／読み順バレットは残す）
4. 素材側の余白をトリミングする（表示を歪ませない）

詳細な素材生成: [figures-and-math.md](figures-and-math.md)

## 偽陽性・偽陰性

- テーマ装飾やページ番号を「はみ出し」と誤認しない
- `object-fit: contain` の余白は歪みではない
- 薄色文字・中腹でのクリップは目視でないと落ちやすい → **目視を廃止しない**
