# HTML / MD 表現カタログ（重要度順）

エージェントは上から優先して選び、下へ行くほど「本当に要るか」を疑う。

## P0 — ほぼ毎回効く

| 表現 | 用途 | 例 |
|------|------|----|
| 相対リンク（`/`） | ファイル・HTML・画像への接続 | `[開き方](../viewer.html)` |
| Markdown 表 | 小さい比較・手順ステップ | 3〜7 行程度まで |
| 再生成コマンドのコードブロック | 再現性 | `bat` / `powershell` / `bash` |
| パスのバッククォート | コピーしやすい成果物指示 | `` `{成果物ディレクトリ}/index.html` `` |

## P1 — Companion HTML

| 表現 | 用途 |
|------|------|
| フィルタ付き一覧 | 評価結果・ログ・CSV |
| 左右（または 3 列）比較 | 入力 / 生成 / 参照 |
| 画像グリッド + キャプション | ギャラリー（MD に大量 `![]` しない） |
| 検索・ページ送り | 行数が多い表 |

MD 側は「目的・リンク・再生成」に薄く保つ。

## P2 — MD 内インライン HTML（プレビューが HTML を許す場合）

| タグ | 用途 | 注意 |
|------|------|------|
| `<details>` / `<summary>` | 長いログ・代替案・生データ | 要約行は短く。ネストは 1 段まで |
| `<figure>` / `<figcaption>` | 図・スクショに説明を付ける | 画像は相対パス |
| `<kbd>` | キー操作の指示 | 多用しない |
| `<br>` | 表セル内の短い改行 | 段落代わりに使わない |
| 素の `<a href>` | MD リンクで足りないアンカー | 可能な限り MD リンク優先 |

GitHub / 多くの MD プレビューは上記を許可。厳密 CommonMark のみのホストでは P1/P2 画像に退避。

## P3 — フロー・図

| 手段 | 優先 |
|------|------|
| `.mmd` → SVG/PNG → `<figure>` or `![]()` | **一次**（描画ホスト非依存） |
| \`\`\`mermaid フェンス | 二次（GitHub 等で描画確実なとき） |
| ASCII / 罫線図 | 最終手段（テキストのみ強制時） |

主経路以外は図に入れず `<details>` か箇条書き。

## 避ける（この skill の範囲外・好み不一致）

- VisualCave 系の多テーマ・Inter・Pastel・ドロップシャドウ一式の丸写し
- 紫グラデ / カードだらけ / 絵文字装飾 UI
- Obsidian 専用 `![[wikilink]]` を配布ドキュメントの主経路にする
- MD に巨大 Base64 画像や数 MB のインラインデータ
- アーキテクチャ全体図の SoT 化（→ `system-structure-viz`）
- Canvas / React ダッシュボード（→ canvas skill）
- 外部データやログを HTML エスケープせず文字列連結で埋め込むこと
