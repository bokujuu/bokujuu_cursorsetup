# Excel 成果物の表記・品質規約

ツール（COM / openpyxl / pandas）に依存しない、成果物そのものの規約。
既存テンプレに規約がある場合は、本書よりそちらを優先する。

配置・背景色（入力＝黄／計算＝灰の役割配色）・印刷規律は
[design-and-layout.md](design-and-layout.md)、作り方・検証は [build-and-verify.md](build-and-verify.md)。
本書は**表記・数式・出典注記**を担当する。

## 数式エラー（残してはいけない値）

| エラー | 主因 | 対処 |
|--------|------|------|
| `#REF!` | 参照先の削除・無効な参照 | 参照範囲を再確認。行列削除の影響を点検 |
| `#DIV/0!` | 0 / 空セルでの除算 | 分母を `IF`/`IFERROR` で保護 |
| `#VALUE!` | 型不一致（文字×数値など） | 入力型・全角数字混入を確認 |
| `#N/A` | 検索一致なし（VLOOKUP 等） | キーの表記揺れ・範囲を確認 |
| `#NAME?` | 関数名・名前定義の誤り | 綴り・名前定義・地域設定を確認 |
| `#NULL!` | 範囲演算子の誤り | 範囲指定（`:` `,`）を確認 |
| `#NUM!` | 不正な数値計算 | 引数の範囲・桁あふれを確認 |

## 計算は数式で持つ

- 合計・平均・比率・差分・成長率などは、Python で計算した確定値を書き込まず
  Excel 数式として埋める（元データ変更で再計算できる状態を保つ）。
  - 悪い例: `sheet['B10'] = total`（5000 を固定）
  - 良い例: `sheet['B10'] = '=SUM(B2:B9)'`
- 確定値スナップショットが要件のときだけ確定値を書き、その旨を成果物（セル注記等）に明示する。

## 数値・日付の書式

- **年**: 文字列扱い（`2024`。`2,024` のような桁区切りを付けない）。
- **桁区切り**: 金額・件数は `#,##0`。
- **通貨**: `$#,##0` / `¥#,##0` など。単位は見出しに明示（例: 「売上（千円）」）。
- **ゼロ**: 必要に応じて `-` 表示（例: `#,##0;(#,##0);-`）。
- **パーセント**: 既定は小数 1 桁（`0.0%`）。
- **負数**: 用途に応じて括弧 `(123)` か `-123` を統一。混在させない。
- **倍率**: バリュエーション等は `0.0x`。

## 文字色の色分け（金融モデル等・任意）

財務モデル等で慣習的な**文字色**の色分けが有効な場合の既定（既存テンプレがあればそちらを優先）。
**背景色によるセル役割の配色**（入力＝黄／計算＝灰など）は [design-and-layout.md](design-and-layout.md)
を正とする。本節は文字色のみを扱い、両者は併用できる。

- **青字**: ハードコード入力値・シナリオで変える数値。
- **黒字**: すべての数式・計算。
- **緑字**: 同一ブック内の他シート参照。
- **赤字**: 他ファイルへの外部参照。

データ取込用 CSV/XLSX や一覧表など、色分けが不要な成果物では適用しない。

## ハードコード値の出典注記

数式にできず確定値を置く場合は、根拠を残す。

- 形式: `出典: [システム/文書], [日付], [具体的な参照], [URL があれば]`
- 例: `出典: 日本郵便 KEN_ALL, 2026/06/15, utf-readme, https://www.post.japanpost.jp/...`
- 置き場所: 該当セルのコメント、または表の末尾なら隣接セル。

## 既存テンプレの踏襲

- 既存ファイルを更新するときは、配色・桁・フォント・命名・シート構成をそのまま踏襲する。
- 既存の規約は本書の既定値より常に優先する。標準化を勝手に押し付けない。

## 数式チェックリスト（作成時）

- [ ] 参照セルがすべて存在し、意図した位置を指す（`#REF!` 予防）。
- [ ] 分母の 0/空を確認した（`#DIV/0!` 予防）。
- [ ] 投影期間で数式が一貫している（オフバイワン無し）。
- [ ] 想定外の循環参照が無い。
- [ ] エッジケース（0・負数・巨大値・空）で破綻しない。
- [ ] クロスシート参照の形式（`Sheet1!A1`）が正しい。
