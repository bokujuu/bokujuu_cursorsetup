# 読み物の緩急

具体的な観察とその意味づけを行き来し、読者が考えながら読める文章にする。

- 文や段落の長さ、具体と抽象の距離を内容に合わせて変える。拍数や段落数を固定しない。
- 問い・ためらい・転回は、対象の事実や語り手の実際の判断から作る。緊張を維持するために結論を隠したり、架空の体験を足したりしない。
- 本文の進行を実況するだけの文を減らす。削ると論理が飛ぶ箇所は、具体的な関係を説明する。
- 立てた問いは必要な位置で回収する。全段落への問いの設置や緊張台帳は不要。
- 編集後は通読し、必要な前提が落ちていないか、型の繰り返しが増えていないかを確かめる。

技術文書の構造変更や一般的な自然さの修正まで必要な場合だけ、対応する文章スキルを参照する。
