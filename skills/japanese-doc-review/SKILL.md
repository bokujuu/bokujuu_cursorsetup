# 日本語文書のレビュー

対象本文と最新の依頼を読み、実際に誤解や読みづらさを生む箇所を指摘する。対象が指定ファイルや直前の草稿から分かれば、それを読む。

- 観点が未指定なら、構成・文法・表記・誤字を確認する。構成の問題を理由に他の指定観点を省略しない。
- 指摘には対象位置、短い引用、問題の根拠、修正方針を添える。同じ原因はまとめ、重要なものから示す。
- 件数を埋めるための指摘や、好みだけの言い換えは出さない。確認できなかった範囲は明示する。
- レビューだけの依頼では対象本文を書き換えない。結果ファイルは保存依頼がある場合に使う。
- 既存レビューの更新では解決済みの指摘を外す。過去のCONTEXTより最新のユーザー条件を優先する。

観点を詳しく調べる場合だけ、該当資料を読む。

- [構成](references/01-structure.md)
- [文法](references/02-grammar.md)
- [表記](references/03-style.md)
- [誤字](references/04-typo.md)

通常の回答は簡潔な指摘一覧でよい。自動処理などで固定形式を指定された場合だけ [結果形式](references/review-result-format.md) を使う。
