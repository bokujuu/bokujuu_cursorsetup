# カバレッジ行列

生成前に、次の表を **プロジェクト向けに削って** 埋める。各行はデータ上で追跡可能にする（`fixture_tag` 列、
コメント、または manifest の `anchors` 一覧）。

## 使い方

1. 列 `カテゴリ` / `ケース` / `tier` / `行IDまたはタグ` / `根拠（仕様・チケット）` を用意する。
2. `smoke` では必須行（下記 ○）をすべてカバー。
3. `dev` ではグループ内にばら撒き、`stress` では同一カテゴリのバリエーションを増やす。
4. 根拠のない行は書かない。不明は `要確認`。

## 汎用カテゴリ（チェックリスト）

### スカラー・文字列

| ケース | smoke | 例 |
|--------|-------|-----|
| 正常代表値 | ○ | 典型的な長さ・文字種 |
| 空文字 `""` | ○ | 必須でない列 |
| NULL / 欠損 | ○ | スキーマが許す場合 |
| 空白のみ `"   "` | ○ | trim の有無 |
| 前後空白 | ○ | `" value "` |
| 最大長ちょうど | ○ | maxlength |
| 最大長 + 1（negative） | ○ | バリデーション |
| 最小長・0 文字 | △ | 数値 0 と区別 |
| 改行・タブを含む | △ | CSV クォート |
| 全角のみ / 半角のみ / 混在 | ○ | 日本語業務 |
| 結合文字・互換文字 | △ | 検索・正規化 |
| 絵文字・サロゲート | △ | UI・DB |
| SQL / 式っぽい文字列 | △ | インジェクションではなくパース |

### 数値・日付

| ケース | smoke | 例 |
|--------|-------|-----|
| 0 | ○ | ゼロ除算・表示 |
| 負数 | ○ | 許可/不許可 |
| 小数端（0.1 + 0.2） | △ | 丸め |
| 境界日（月末・うるう年） | ○ | 2/29, 3/31 |
| タイムゾーン跨ぎ | △ | UTC vs JST |
| 未来日・過去日 | ○ | 業務ルール |
| シリアル値日付（Excel） | ○ | PCAF 型 |

### 識別子・整合

| ケース | smoke | 例 |
|--------|-------|-----|
| 主キー重複（negative） | ○ | 別ファイル |
| 外部キー正常 | ○ | 参照先アンカー |
| 孤児 FK（negative） | ○ | 存在しない親 |
| 循環参照 | △ | グラフ |
| 論理削除済み親を参照 | ○ | ソフトデリート |
| ソート安定性 | ○ | 同キー複数行 |

### バッチ・ファイル

| ケース | smoke | 例 |
|--------|-------|-----|
| ヘッダのみ | △ | 空ファイル |
| データ 0 行 | ○ | 取込スキップ |
| 列欠損・列順違い（negative） | ○ | スキーマ検証 |
| 文字コード UTF-8 BOM 有無 | ○ | Excel 取込 |
| 改行 CRLF / LF | △ | 環境差 |
| 数値のゼロ埋め文字列 | ○ | `dtype=str` 取込 |

### ワークフロー・状態（業務アプリ）

| ケース | smoke | 例 |
|--------|-------|-----|
| 各状態 1 件以上 | ○ | 下書き/申請/承認… |
| 差戻し後再申請 | △ | 同一キーで履歴 |
| 権限外操作相当データ | △ | negative と役割分担 |
| 同時更新競合の元データ | △ | 楽観ロック |

## qa-multi-perspective との対応

| ペルソナ | データ設計での問い |
|----------|-------------------|
| P4 データ整合 | UI を見ずに DB/ファイルだけで不変条件は成り立つか |
| P5 移行担当 | 件数・NULL 率・FK・文字コードは仕様と一致するか |
| P3 敵対的操作 | 境界・不正値は negative tier で再現可能か |

観点レビューは `qa-multi-perspective` の migration モードを併用する。
