# リポジトリのエージェント設定

README、実装、既存の設定から、目的・正本・実行コマンド・固有の不変条件を確認する。履歴は現在の資料だけで判断できない場合に調べる。

- AGENTS.md には、その repo で作業するために必要な情報だけを置く。一般的な推論手順やモデルの基本動作は重ねない。
- 既存設定を直すことを優先する。新スキル・registry・skill-memory は繰り返す不足か明示依頼がある場合だけ作る。
- Cursor・Codex 共通の指示は AGENTS.md にまとめる。固有のルール形式やツール名は、利用環境を確認して使う。
- 検証は変更された設定とその参照先を対象にする。独立チェックは高リスクの不変条件に必要な場合だけ追加する。
- 最新のユーザー依頼、現行コード、検証結果に合わせて古い指示を削る。更新時刻だけで内容の正誤を決めない。

新設が必要なときの雛形は [assets/templates/](assets/templates/)。必要なファイルだけ取り出し、空の管理ファイルを増やさない。
