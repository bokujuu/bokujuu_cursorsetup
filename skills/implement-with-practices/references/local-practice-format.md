# Local Practice Format

Repo-local skills generated by this bundle follow a narrow deterministic contract.

## Registry

- Path: `.codex/practice-registry.json`
- Fields per entry: `slug`, `summary`, `trigger_keywords`, `verification_commands`, `source_urls`, `skill_path`, `status`
- Allowed status values: `draft`, `approved`

## Skill Layout

- `SKILL.md`
- `agents/openai.yaml`
- `references/observations.md`
- `references/sources.md`
- Optional `scripts/` only when a deterministic helper is actually needed

## Promotion

- Promotion changes `status` from `draft` to `approved`.
- Promotion writes a snippet under `.codex/practice-snippets/`.
- Promotion does not edit repository `AGENTS.md` directly.
