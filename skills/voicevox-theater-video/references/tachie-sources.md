## 取得手順

1. 取得ページでファイル名・キャラクター・更新日時を確認する。
2. uploader.jp の利用規約を確認して同意し、ページのダウンロード操作を行う。`downloadx.getuploader.com` の一時 URL を skill の恒久設定として保存しない。
3. 制作対象リポジトリのローカル素材置き場（例: `assets/tachie/tracker/`）へ ZIP を保存し、SHA-256 を確認する。
4. ZIP を展開し、PSD のまま保管する。PSD が 1 枚だけの配布でも、口・表情レイヤーを壊さず、ランタイム用 PNG は案件側でエクスポートする。
5. `closed` / `open` の口状態と、`default` / `question` / `think` / `understand` / `surprise` の表情を、実際に存在するレイヤーから選ぶ。存在しない表情を黙って別名へ読み替えない。
6. 配布ページの表示文は「良識の範囲内で活用ください」であり、個別の詳細ライセンス本文ではない。公開配布・再配布・別キャラクターへの流用を行う場合は、素材内の説明と配布元を再確認し、作者名・取得元のクレジットを残す。

## 代替候補

入口には旧版の [冥鳴ひまり](https://uu.getuploader.com/trac/download/10) と [春日部つむぎ](https://uu.getuploader.com/trac/download/8) も掲載されている。優先版を取得できないときだけ、キャラクターが一致することを確認して代替にする。
