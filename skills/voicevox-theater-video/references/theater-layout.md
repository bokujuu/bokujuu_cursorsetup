# 劇場レイアウト

Updated: 2026/08/05 10:32

数値・話者メタの完全表は [theater-presets.md](theater-presets.md)。

## 画面

| 要素 | 規約 |
|------|------|
| 解像度 | 1920×1080 |
| スライド | 白〜ごく薄い灰青背景（`slide_theme: light`）。下部は立ち絵のため余白を多めに |
| 解説役 (`teacher`) | 左下、顔を中央向き。既定素材は左右反転（`face_flip: true`） |
| 聞き手 (`listener`) | 右下、顔を中央向き（既定 `face_flip: false`） |
| 字幕 | 下段の見えない枠内で下寄せ。枠線・吹き出し箱は出さない |
| 制作メモ字幕 | 禁止（dialogue-writing と同じ） |

## 顔位置アンカー

- 画面中央 ± **42% 幅** に顔重心を置く（`FACE_GAP = int(W * 0.42)`、左右対称）
- 表情・ハテナ・ハートで `face_x` を再計算しない（`default` 基準で固定）
- 頭上端 Y はレイアウト確定後に固定（既定 `BUST_TOP_Y ≈ 552`。拡縮時は上揃え）

## 立ち絵スケール（プロファイル既定）

| 呼び | 値 | 備考 |
|------|-----|------|
| `BODY_ON_SCREEN_H` | 962 | 全身 on-screen 高さ |
| `SPRITE_PAD_TOP` | 220 | エクスポート上余白と一致 |

胴体はクロップせず、下端を画面外へ出す（バストアップ切りではなく全身スプライト）。

## 話者テーマ色

役割 ID を正とし、色は `meta` またはプロファイル既定で渡す。

| 役割 ID | プロファイル既定 | RGB |
|---------|------------------|-----|
| `teacher` | 紫（ひまり） | (155, 93, 229) |
| `listener` | 黄土（つむぎ） | (232, 168, 56) |

案件で変えてよい。字幕の外縁に使う。話者名はキュー本文に埋め込まず `meta.speakers` で解決する。

## 表情

| tag | 用途 |
|-----|------|
| default | 平常 |
| question | 疑問・食い付き（はてな可） |
| think | 考え込み・汗可 |
| understand | 納得（聞き手側のハート等可） |
| surprise | 驚き |

キューの `utterances[].expression` が SoT。非話者は `default`＋口閉じ。
