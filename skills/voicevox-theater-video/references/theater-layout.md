# 劇場レイアウト

## 画面

| 要素 | 規約 |
|------|------|
| 解像度 | 1920×1080 |
| スライド | 白〜ごく薄い灰青背景。下部は立ち絵のため余白を多めに |
| 解説役 | 左下、顔を中央向き |
| 聞き手 | 右下、顔を中央向き |
| 字幕 | 下段の見えない枠内で下寄せ。枠線・吹き出し箱は出さない |
| 制作メモ字幕 | 禁止（dialogue-writing と同じ） |

## 顔位置アンカー

- 画面中央 ± **42% 幅** に顔重心を置く（左右対称）
- 表情・ハテナ・ハートで `face_x` を再計算しない（`default` 基準で固定）
- 頭上端 Y はレイアウト確定後に固定（拡縮時は上揃え）

## 立ち絵スケール（参考値）

試作で収束した目安（2×相当 bust 高さ≈980 を基準）:

| 呼び | 全身 on-screen 高さの目安 |
|------|---------------------------|
| 1.0× | 全身 ≈962px（頭位置は 1.2× 時代の top を維持して上揃えした例あり） |
| 1.2× | bust 高さ ≈600 |

胴体はクロップせず、下端を画面外へ出す。

## 話者テーマ色（例）

| 役割 | 例 | RGB |
|------|-----|-----|
| 解説役（ひまり） | 紫 | (155, 93, 229) |
| 聞き手（つむぎ） | 黄土 | (232, 168, 56) |

案件で変えてよい。字幕の外縁に使う。

## 表情

| tag | 用途 |
|-----|------|
| default | 平常 |
| question | 疑問・食い付き（はてな可） |
| think | 考え込み・汗可 |
| understand | 納得（つむぎハート可） |
| surprise | 驚き |

キューの `utterances[].expression` が SoT。
