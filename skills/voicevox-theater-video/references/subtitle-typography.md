# Subtitle typography (display size & symbols)

Updated: 2026/08/01 20:40

字幕の**見た目サイズ**と**記号の書き方**を揃えるための不変条件。  
SoT は `utterances[].narration`。読みは `pronunciation.yml` → `tts_text`（画面に出さない）。

## 分類（描画前）

`$...$` の flatten / mixed 分割を**先**に行い、残った通常テキストだけを span 分類する。  
未処理の `$` に対して全角化や光学補正をかけない。

**分類の優先順（固定）:**

1. raw `$...$` を除外（flatten 成功分は通常テキストへ、失敗分は MATH_MASK）  
2. latin 識別子一塊（`SU(2)`、`v1.2`）→ shrink。単独 `x` / `J` は識別子にせず boost  
3. 数字 run → boost  
4. Greek / `ℏ` 等 → boost  
5. 残り（和文・演算子・小数点）→ cjk  

| span | 例 | 描画 |
|------|----|------|
| CJK / 演算子 | 漢字・かな・句読点・`(` `/` `·` `×` | 基準サイズ |
| boost 数字 | `第3章` の `3`、`3.1` の数字、`図28` | 実測インク高さで等方拡大（基準=`第`/`章` 中央値） |
| boost 変数 | 単独 `J` / `i` / `ℏ` / `φ`（flatten 後） | 同上。小文字 Latin は `あ` 基準＋倍率上限 ≈1.45（Sol 承認） |
| shrink 識別子 | `SU(2)`、`API`、`v1.2` | 約 0.72。識別子は一塊。内部数字を再 boost しない |
| MATH_MASK | flatten 不能な `$...$` | matplotlib で和文高さに合わせたビットマップ |

**禁止:** 全角数字・全角 Latin を「高さ合わせ」の手段にしない（横幅だけ増え、高さは足りない）。  
**フォールバック:** ink 高さ ≤1 または測定失敗時は scale=1（拡大しない）。

### 回帰例

| 入力 | 期待 |
|------|------|
| `第3章` | `3` boost、第/章 cjk |
| `3.1` | `3`/`1` boost、`.` cjk |
| `SU(2)` | 一塊 shrink（中の `2` を再 boost しない） |
| `v1.2` | 一塊 shrink |
| 単独 `x` / `J` / `ℏ` | boost |
| `x×p` | `x`/`p` boost、`×` cjk |
| `1-(i/ℏ)` | 数字・`i`・`ℏ` boost、演算子 cjk |

## 記号・表記をいつ使うか

1. **節・章・図の番号** — 原稿 SoT は半角（`3.1`、`第3章`）。画面では数字 span を光学拡大。小数点は拡大しない  
2. **数学の変数・式** — `$...$`。単純式は unicode flatten（半角のまま）。TTS カナを字幕に出さない  
3. **群名・定理名などのラテン固有表記** — 半角のまま一塊で shrink  
4. **原稿 SoT の書き換え** — cues の半角を永続全角化しない（表示パイプラインのみ）

## flatten の境界

- 可: 単一変数、`x\times p`、`1-(i/\hbar)J·n dφ` のように記号置換で `\` と `_^{}` が消える式  
- 不可（MATH_MASK）: 分数・根号・上下付き・大きな括弧伸長・行列など

## 縁取り

- 余白 `outer_w+8` 付きキャンバスで膨張する  
- 正方形 MaxFilter 単体は使わず、円形ダイレーション系で輪郭に沿わせる  
- 光学拡大後の advance で改行幅を再計算する（拡大を元幅に押し込まない）

## 検証チェック

- [ ] `第3章` の `3` のインク高さが「第」「章」とほぼ一致（全角化ではなく boost）  
- [ ] `3.1` / `図28` の数字も同様  
- [ ] `$J$` / flatten 後の単独変数が前後和文と揃い、巨大化していない  
- [ ] `SU(2)` だけがやや小さい（内部の `2` を再拡大しない）  
- [ ] 字幕に TTS カナ（三点一、エイチバー）が出ていない  
- [ ] 未 flatten の `$...$` に光学補正をかけていない
