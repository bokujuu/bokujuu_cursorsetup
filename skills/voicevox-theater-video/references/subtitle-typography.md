# Subtitle typography (display size & symbols)

Updated: 2026/08/01 19:50

字幕の**見た目サイズ**と**記号の書き方**を揃えるための不変条件。  
SoT は `utterances[].narration`。読みは `pronunciation.yml` → `tts_text`（画面に出さない）。

## 分類（描画前）

描画前に span を次へ分類する（**1文字の `[A-Za-z0-9]` では縮小しない**）。

| span | 例 | 描画サイズ |
|------|----|------------|
| 和文 | 漢字・かな・句読点 | 基準（フル） |
| 和文数値 | `第3章`、`3.1`、`90度`、`図28` | 基準。**表示時のみ**全角数字へ（原稿 SoT は半角のまま） |
| latin 識別子 | `SU(2)`、`Wigner–Eckart`、`API` | 約 0.72 倍（識別子が `[A-Za-z]` で始まるときだけ）。括弧内の数字は半角のまま |
| math | `$J$`、`$\\hbar$`、交換関係など | 基準。単純式は同一フォントへ flatten（必要なら全角 `Ｊ`）。複雑式のみ高さ合わせビットマップ |

## 記号・表記をいつ使うか

1. **節・章・図の番号** — 原稿 SoT は半角アラビア（`3.1`）。画面では和文文脈の数字だけ全角化して漢字と視覚高を揃える（`SU(2)` 内の数字は半角）  
2. **数学の変数・式** — `$...$`。単純トークン／近似可能な式は unicode flatten。TTS 用カナを字幕に出さない  
3. **群名・定理名などのラテン固有表記** — 半角のまま残し、識別子としてのみ縮小  
4. **原稿 SoT の書き換え** — cues の半角を永続的に全角へ書き換えない（表示パイプラインで光学調整）

## 縁取り

- 余白 `outer_w+8` 付きキャンバスで膨張する  
- 正方形 MaxFilter 単体は使わず、円形ダイレーション系で輪郭に沿わせる  

## 検証チェック

- [ ] `第3章` の `3` が「第」「章」と同じ視覚高さ  
- [ ] `3.1` がフルサイズの半角  
- [ ] `$J$` / flatten 後の記号が前後和文と揃い、巨大化していない  
- [ ] `SU(2)` など識別子だけがやや小さくなる（任意）  
- [ ] 字幕に TTS カナ（三点一、エイチバー）が出ていない
