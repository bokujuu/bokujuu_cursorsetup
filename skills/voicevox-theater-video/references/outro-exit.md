# 退場演出（Y 回転 → 弾む歩きスライドアウト）

Updated: 2026/08/05 10:32

本編の最後（最終スライドの pause のあと）に、**無音**で両キャラが外側を向いて歩き去り、フェードアウトして終わる。

## 意図

1. **Y 軸回転**: 画面上の縦軸まわりにくるっと回し、中央向き → 外側向きにする（2D では `scale_x = cos θ`、θ: 0→π。負で左右反転＝外側向き）
2. **スライドアウト**: 導入と同じ弾む歩きパラメータで、定位置 → 画面外へ
3. **フェードアウト**: 導入のフェードインを時間反転（歩きの後半 `FADE_IN_FRAC` で α 1→0）

導入中と同様、退場中は口閉じ・字幕なし。

## パラメータ（導入と共通）

| 項目 | 値 |
|------|-----|
| 弾む速さ | ≈6.7（`BOUNCE_SPEED = 20/3`） |
| 弾む高さ | 8（≈32px） |
| X 移動距離 | `SLIDE_IN_DIST ≈ 520` |
| 歩き尺 | 導入と同じ（例: 2.4s） |
| 回転尺 | 例: 0.7s（調整可） |
| フェード | 歩きの最後 40% で α→0 |
| 左右バウンス | 導入と同じく **同位相** |

## タイムライン

```text
… → [最終発話] → [end pause] → [outro 回転] → [outro 歩き+フェード] → 終了
```

## 検証

- 退場クリップが無音
- 回転後に外側を向いたまま歩き始める
- フレームアウトとフェードが同時に完了し、唐突なカットになっていない
