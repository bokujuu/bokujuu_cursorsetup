# ブックマークレット開発ベストプラクティス

## プロジェクト構造

- **src/**: 読みやすい形式のソースコード（`.js`ファイル）を配置
- **dist/**: ビルド済みワンライン化コードを出力（`.gitignore`に含める）

## ビルドプロセス

- `src/` 内のすべての `.js` ファイルを自動処理
- コメント削除（複数行 `/* */` と単行 `//`）
- 改行・タブ・キャリッジリターン削除、連続空白を1つに統合
- `javascript:` プレフィックスを付与して `dist/` に出力

## コード品質管理

- **ESLint**: ブラウザ環境（`browser: true`）、ES2021、推奨ルール、`console`許可
- **Prettier**: セミコロン、シングルクォート、タブ幅2、トレーリングカンマ

## 開発フロー

1. `src/` ディレクトリに `.js` ファイルを作成し、読みやすい形式でコードを記述
2. `npm run build` でビルド実行（ワンライン化）
3. `npm run lint` でリンターチェック、`npm run format` でコードフォーマット
