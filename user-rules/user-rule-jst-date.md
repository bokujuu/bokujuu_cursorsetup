# JST日付取得ルール

## 目的と適用範囲
- 更新履歴、CHANGELOG、ルールファイルのバージョン情報などに正確なJST（日本標準時）の日付と時刻を記述するためのルールを定義する。
- 日付書式: `YYYY/MM/DD HH:MM`（例: `2025/11/25 11:04`）

## 日付取得方法の優先順位

### 1. PowerShellコマンド（推奨・低コスト）
- **コマンド**: `powershell -Command "Get-Date -Format 'yyyy/MM/dd HH:mm'"`
- **使用方法**: 日付が必要な箇所で、このコマンドを実行して結果を記述する。
- **利点**:
 - スクリプトファイル不要
 - 実行が高速（1コマンドで完了）
 - Windows標準機能のみ使用
- **注意点**:
 - システム時刻がJSTに設定されている必要がある
 - タイムゾーン変換なし（システム時刻をそのまま使用）

### 2. Pythonスクリプト（フォールバック・確実性重視）
- **使用方法**: 標準ライブラリ（`datetime`と`zoneinfo`）を用いた時刻取得スクリプトを実行する。
- **実装**: システム時刻がJSTでない場合や、確実にJSTを取得したい場合に使用する。
- **利点**:
 - システム時刻設定に関係なく確実にJSTを取得
 - タイムゾーン変換が確実（`zoneinfo.ZoneInfo("Asia/Tokyo")`を使用）
- **注意点**:
 - Python実行環境が必要（Python 3.9以降推奨）
 - プロジェクトごとにスクリプトの場所が異なるため、適切なスクリプトを実行する

## 使用場面

### 更新履歴の記述
- CHANGELOG.mdの更新履歴セクション
- ルールファイルのバージョン情報セクション
- その他のドキュメントの更新日時

### 記述例
```markdown
## バージョン1.0.0 (2025/11/25 11:04)

### 主な変更点
- JST日付取得ルールを追加
```

## 実装時の注意事項

- **通常**: PowerShellコマンドを使用（低コスト）
- **フォールバック**: システム時刻がJSTでない場合や確実性が必要な場合はPythonスクリプトを使用
- **日付取得**: ファイル作成・更新時は必ず実際の日時を取得して記述する（推測や記憶に頼らない）
- **書式統一**: すべての日付は `YYYY/MM/DD HH:MM` 形式で統一する

## 技術的詳細

### PowerShell実装
- `Get-Date`コマンドレットでシステム時刻を取得
- `-Format`パラメータで書式を指定
- システム時刻がJSTであることを前提とする

### Python実装（オプション）
- `datetime`モジュールと`zoneinfo`モジュールを使用
- `zoneinfo.ZoneInfo("Asia/Tokyo")`でJSTタイムゾーンを指定
- `strftime("%Y/%m/%d %H:%M")`で書式を指定
- 外部依存なし（Python 3.9以降の標準ライブラリのみ）
