# コードレビューチェックリスト

## 概要
品質、セキュリティ、保守性を確保するための徹底的なコードレビューを実施するための包括的なチェックリスト。

## レビューカテゴリ

### 機能性
- [ ] コードが期待通りに動作する
- [ ] エッジケースが適切に処理されている
- [ ] エラーハンドリングが適切に実装されている
- [ ] 明らかなバグや論理エラーがない

### コード品質
- [ ] コードが読みやすく、適切に構造化されている
- [ ] 関数が小さく、単一責任に集中している
- [ ] 変数名が分かりやすい
- [ ] コードの重複がない
- [ ] プロジェクトの規約に従っている
