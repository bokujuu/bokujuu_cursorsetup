# 全テストの実行と失敗の修正

## 概要
完全なテストスイートを実行し、失敗を体系的に修正して、コード品質と機能性を確保する。

## ステップ
1. **テストスイートの実行**
   - プロジェクト内のすべてのテストを実行
   - 出力をキャプチャし失敗を特定

2. **失敗の分析**
   - タイプ別に分類：不安定、破損、新しい失敗
   - 影響に基づいて修正の優先順位を決定
   - 失敗が最近の変更に関連しているかチェック

3. **問題の体系的修正**
   - 最も重要な失敗から開始
   - 一度に一つの問題を修正
   - 各修正後にテストを再実行
