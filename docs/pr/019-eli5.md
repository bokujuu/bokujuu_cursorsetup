# PR 019 — eli5（原文取込）

更新: 2026/08/22 21:58

## 目的

Anthropic コミュニティプラグイン [eli5](https://github.com/anthropics/claude-plugins-community/tree/main/eli5) を、スキル本文は改変せずグローバル skill として同梱する。`/eli5` および「超簡単な絵解説」依頼で、大きな絵と少ない言葉の HTML 成果物を出す。

## 採用判断

- **入れる**: `SKILL.md` / `README.md` / `.claude-plugin/plugin.json` の原文。複数 repo で使える説明スタイル
- **入れない**: スキル本文の翻訳・拡張。`$ARGUMENTS` は Claude Code 由来のプレースホルダとして原文どおり残す

## 既存との境界

| 既存 | 境界 |
|------|------|
| `md-html-visual-doc` | 比較表・ギャラリー・手順の視覚ドキュメント。eli5 は「知らない人向けの大きな絵」 |
| `slide-narration-video` / `voicevox-theater-video` | スライド＋音声。eli5 は静止 HTML |
| `japanese-technical-writing` | 技術文書の論理。eli5 は数式や用語定義を先に置かない |
