# データ安全ルール（エージェント向け SoT）

分析リポジトリでエージェントが守る不変条件。人間向けの詳細はプロジェクトのデータカタログに追記する。

## ディレクトリの意味

| パス | 扱い |
|------|------|
| `data/raw/` | 不変。読み取りのみ。git に含めない（verify で検出） |
| `data/external/` | 外部取得の不変コピー。同上 |
| `data/interim/` | 中間加工。再生成可能 |
| `data/processed/` | 分析用の確定加工結果 |
| `outputs/` | 図・表・レポート（成果物） |

## コミット禁止

- raw / external の実データ
- API キー・トークン・接続文字列
- 個人を特定できるレコード（匿名化前）

## エージェントの作業順

1. 指標・定義を `docs/agent/` で確認
2. raw を直接書き換えない
3. 出力先を `outputs/` または `data/processed/` に明示
4. PR 前に verify 3 本を実行
